# Jordan Vyater — personal portfolio

Live website: https://jkv720.github.io/

A responsive portfolio made with AI assistance using HTML and CSS.

## Editing

Edit `index.html` for content and `styles.css` for appearance. The profile photo is `jordan-vyater.png` and the favicon is `favicon.svg`. No build tools or dependencies are needed.

## Publishing

GitHub Pages publishes the `main` branch from the repository root. Changes committed to `main` publish automatically.
